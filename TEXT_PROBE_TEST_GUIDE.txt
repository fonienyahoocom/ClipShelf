ClipShelf v2.6.5 文字擷取測試 — 你只需要照做，不需要看懂報告
==============================================================

每一次測試：
1. 把滑鼠移到要測的文字區塊附近。
2. 右鍵桌面 ClipShelf 浮動圖示。
3. 按「擷取文字」。
4. 畫面上方會顯示提示。
5. 把滑鼠放到目標區塊內，左鍵一下。
6. 完成後 Explorer 會顯示一個 TextProbe_*.txt。
7. 把這個 txt 丟回 ChatGPT。

建議依序做三次：

A. 普通 ChatGPT 回答文字
-----------------------
目的是當正常對照組。找一段普通回答文字，對著文字區塊點一下。

B. ChatGPT 特殊程式碼區塊
-------------------------
最好使用內容已知的 code block，例如：

ROOT
  two-spaces
    four-spaces

blank-line-above
中文ABC123
symbols: !@#$%^&*()_+-=[]{};:'",.<>/?

注意：前導 2 個空白、4 個空白與中間空行是重要測試資料。
TAB 可以另外測，但 TAB 變 spaces 本身不直接判定失敗。

C. Python / 程式執行輸出區
--------------------------
若你有可產生輸出的區塊，可以用這種固定輸出：

OUT-001
OUT-002

OUT-004

同樣對著「輸出結果區塊」執行一次擷取。

你不需要自己判斷 PASS / FAIL。
把 A / B / C 三份 txt 直接交回目前主控聊天室即可。
