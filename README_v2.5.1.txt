ClipShelf v2.5.1 - COLLAPSIBLE SIDEBAR + FULL TEXT SELECT

本版只針對兩個 UX 問題做小步更新，不重做 v2.5 已穩定的其他功能。

1. 左側父資料夾可直接收起 / 展開
   - 有子資料夾的節點會顯示 ▾ / ▸。
   - 左鍵點父資料夾：展開時收起子資料夾；收起時再次點擊就叫回子資料夾。
   - 收藏 / 暫存 / AI 用語 / 快速用語等有子資料夾時也遵守相同規則。
   - ⠿ 仍然只負責拖曳，不會因為拖曳而誤收起。
   - 收起狀態會保存到原本 settings，重新啟動後仍保留。
   - 這只是顯示狀態，不會移動、刪除或改寫任何資料夾內容。

2. 卡片正文左鍵展開完整內容
   - 文字卡片仍預設維持 112px 的緊湊預覽。
   - 左鍵點正文後，該卡片會展開完整文字，不再只看到局部內容。
   - 展開後正文仍是可選文字，可直接反白任意一段。
   - Ctrl+C 或右鍵「複製選取文字」會沿用 v2.5 安全 History 模型：選取片段進入歷史，原始卡片內容不被修改。
   - 展開後提供「收起 ↑」按鈕，避免長文字一直佔滿畫面。

3. 保持不變
   - v2.5 History 安全模型不變。
   - Core / UI 拆分、45 秒 warm standby、一般 / 不干擾模式不變。
   - 沒有新增背景 polling / timer / 網路請求。
   - %LOCALAPPDATA%\ClipShelf 的資料位置不變。

Build：先完整退出舊 ClipShelf，執行 BUILD_EXE.cmd，之後只開 ClipShelf_READY\ClipShelf.exe。
