DATA SAFETY CHECKS
- AnalyzeImport does not call HistoryStore save methods.
- AnalyzeImport does not call ExtractFile / ExtractDirectory and does not create storage/imports directories.
- Duplicate IDs are excluded before content hashing of backup items.
- Duplicate content is excluded from default approved IDs.
- Uncertain items require explicit user opt-in.
- Actual Import still stages under storage/imports and MainWindow still requires SaveNowChecked before success.
- Pre-commit failure path still restores previous in-memory items/folders/settings and discards this import payload.

DEDUP MODEL
- Text: full text SHA-256.
- Image: actual bytes SHA-256.
- File: top-level filename + actual bytes SHA-256.
- Directory: deterministic hash of relative directory/file paths + file content hashes.
- Multi-file ClipItem: order-independent sorted component fingerprints.
