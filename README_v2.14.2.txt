ClipShelf 2.14.2 — 原地編輯與操作穩定性修補

安裝／更新
先從系統匣的 ClipShelf 選單「退出」舊版，再執行 ClipShelf-2.14.2-Setup.exe。
Windows 10/11 x64；安裝程式自含執行環境，不需自行編譯、不需先解除安裝。
程式：%LOCALAPPDATA%\Programs\ClipShelf
資料：%LOCALAPPDATA%\ClipShelf
既有資料路徑與安裝更新邏輯沿用原版，原生 Windows 升級與資料保留仍未實測。

日常操作
普通單擊正文：複製整筆；本次畫面不重排、不自動展開。拖曳選取：選取文字。
正文編輯：點卡片右上方新增的小鉛筆，或右鍵／更多選單「編輯文字」。
也可在正文中選取後按 Delete／Backspace，或直接輸入／Ctrl+V，開始原地草稿編輯。
編輯時正文上方顯示「編輯文字中」及儲存／取消，這些控制只在編輯時出現。
Enter 換行、Ctrl+Enter 儲存、Esc 取消。右鍵提供復原、重做、剪下、複製、貼上、刪除與全選。
完整預覽：右鍵／更多選單「展開全文預覽」；既有「收起」仍可收合。
標題編輯：標題旁的小鉛筆／選單「重新命名標題」；Enter 儲存、Esc 取消。
空白標題恢復內容摘要，正文不因改名而改動。
A 標準／B 緊湊仍與舊選單共用 CompactView，重新開啟延續最後選擇。
未新增卡片底部的編輯文字或複製按鈕。

草稿與資料
編輯期間只改草稿；儲存才寫入既有歷史檔。取消不改原紀錄。
切換其他卡片、資料夾或內容類型時，先處理尚未儲存的修改，取消切換可回到原資料夾。
保存失敗保留原資料及草稿。內容相同的有效紀錄仍拒絕無聲合併。
外部剪貼紀錄仍保存；正在編輯時延後列表重建，保留游標與復原。
正文不再顯示空字串提示框。複製仍更新使用時間、次數與歷史狀態，但不搬動目前畫面的卡片。
