ClipShelf v2.10.1 — Windows 實機最小測試

A. Build
1. 完整退出舊 ClipShelf。
2. 執行 BUILD_EXE.cmd。
3. 必須看到 BUILD SUCCESS。

B. 舊資料安全
1. 啟動 ClipShelf_READY\ClipShelf.exe。
2. 確認原本 History、分類、收藏、檔案仍存在。

C. 最重要的去重測試
1. 先「匯出完整備份」。
2. 不新增任何內容，立刻選同一份備份做「匯入備份（先預掃描去重）」。
3. 預覽不應把全部內容列成新品；同一份資料應主要落在「同一筆 ID 已存在」。
4. 取消即可；預覽階段不應改變 History 或 storage。

D. 混合測試
1. 匯出備份 A。
2. 在 ClipShelf 新增一筆新的文字／圖片／檔案，形成目前資料 B。
3. 匯入 A：舊內容應被跳過，不應產生第二份。
4. 反向情境可用另一份備份，確認只有真正缺少的項目列為「確定是新內容」。

E. 重複內容但不同 ID
若之後有兩份來源不同的備份，且某筆文字／圖片／檔案內容相同但 ID 不同，預覽應列入「內容相同，預設跳過」。

F. uncertain
若某現有圖片／檔案已遺失或無法讀取，可能出現「無法安全判定」。預設不要勾選；只有確定需要時才勾「也匯入無法安全判定的項目」。
