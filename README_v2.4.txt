ClipShelf v2.4 - SIDEBAR ROOTS + MODE SWITCH

本版重點：
1. 左側舊的固定資料夾根節點（收藏 / 暫存 / AI 用語 / 快速用語）也有 ⠿ 拖曳把手。
   - 這些固定根節點可以在左側頂層重新排序，但不會被誤塞成其他資料夾的子資料夾。
   - prompt、占星技巧與其他舊自訂資料夾仍保留 ⠿；舊資料也會從既有內容自動補回資料夾鍵。
   - 自訂根資料夾可以和固定根節點前後排序；自訂資料夾中央停留仍維持「放進去成為子資料夾」的節奏。

2. 「一般模式 / 不干擾模式」現在是可持久保存的正式狀態。
   - 一般模式：保留工作列 / Alt+Tab，方便直接切回完整 ClipShelf。
   - 不干擾模式：使用浮動圖示，不佔一般視窗切換。

3. 兩個地方都能直接切換模式：
   - 桌面浮動 ClipShelf 圖示：右鍵 -> 視窗切換模式。
   - Windows 右下通知區 ClipShelf 圖示：右鍵 -> 視窗切換模式。
   可直接選「一般模式（工作列 / Alt+Tab）」或「不干擾模式（浮動圖示）」，不必先把完整介面叫出來。

4. 工作列 Jump List 同時提供「切換不干擾模式」與「恢復一般模式」。

資料仍使用 %LOCALAPPDATA%\ClipShelf，不會因刪除舊版程式資料夾而清空。
