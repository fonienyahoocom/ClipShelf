ClipShelf v2.5 - MATURE UI + SAFE RECENT HISTORY

本版建立在 v2.4 CURRENT candidate 上，不改低資源 Core/UI 架構。

重點：
1. UI 成熟化（不增加背景輪詢）
   - 頂部操作重新分組：新增文字 / 暫停 / 設定 / 視窗控制。
   - 主內容區增加「全部 / 文字 / 圖片 / 檔案」即時篩選。
   - 卡片層級、間距、類型標籤與底部狀態列重新整理。
   - 左側既有父/子資料夾邏輯完全保留，只做視覺緊湊化，不重做資料夾模型。
   - 底部直接顯示自動保存、一般/不干擾模式、本機保存、Core/UI 狀態。

2. History 語意升級：最近複製 / 最近擷取，與原始資料位置分離
   - 從 prompt、占星技巧、AI 用語、收藏等位置複製一筆內容後，該筆會再次出現在「歷史」。
   - 這不是複製一份新的原始資料；同一個 ClipItem 只多一個 HistoryVisible 狀態。
   - 在「歷史」刪除已有資料夾/收藏/暫存歸屬的紀錄，只會從歷史移除，原資料一定保留。
   - 只有完全沒有其他歸屬的純歷史項目，刪除歷史時才會永久刪除。
   - 多選清理歷史也遵守同一規則。

3. 局部文字複製也會進歷史
   - 在卡片正文反白一小段後 Ctrl+C / 右鍵複製，該片段會成為一筆最近歷史。
   - 原始完整卡片不被修改。

4. 舊資料安全遷移
   - 第一次用 v2.5 開啟時，會按照 v2.4 當時真正可見的 History 狀態做一次 migration。
   - 不會因為模型升級突然把所有舊分類資料塞回 History。

5. 效能邊界
   - 沒有新增常駐 timer / polling / 網路請求。
   - Core + warm UI + 45 秒後卸載完整 UI 的架構保留。
   - 新的篩選/視覺狀態都只在完整 UI 已打開時運作。

資料仍使用 %LOCALAPPDATA%\ClipShelf。
Build：先完全退出舊 ClipShelf，再執行 BUILD_EXE.cmd，只啟動 ClipShelf_READY\ClipShelf.exe。
